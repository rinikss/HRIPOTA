# HRIPOTA

Инструменты ИИ в разработке
В проекте использовалась языковая модель Claude (Anthropic) точечно, для решения конкретных технических задач.
Где применялась модель:
Сложная логика на JavaScript — анимация переходов между страницами с градиентными полосами, sticky-скролл с синхронизацией карточек и текста, управление состоянием форм с динамическим контентом в зависимости от выбранной услуги, IntersectionObserver для каскадного появления элементов, отладка race condition в последовательных анимациях.
Что делалось вручную:
Вся вёрстка HTML и CSS, визуальные решения, подбор градиентов и пропорций, структура страниц, тексты, подбор фотографий, общая концепция и дизайн-система.
